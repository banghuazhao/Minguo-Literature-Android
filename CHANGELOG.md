# Changelog

## 1.3.0 (version code 12)

- Expanded the offline collection to 64 works with simplified and traditional Chinese text, author introductions, and corrected book attribution.
- Redesigned browsing and reading with search, author shelves, chapter navigation, saved progress, favorites, reader appearance controls, and text to speech.
- Added display language choices for English, Chinese, Japanese, Spanish, French, German, and Hindi.
- Updated the Android build to target SDK 37 and modernized billing and advertising dependencies.
- Added an age screen and regional advertising consent controls. Readers who skip age selection or are under 21 can read without ads. Advertising data use can be changed in More.
- Added release signing and ad ID validation, data backup exclusions for privacy choices, and emulator test coverage.
